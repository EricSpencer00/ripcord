RIPCORD

Offline masteringmacOS 14+Universal · 2 MBMIT

Drop a track on it, get a mastered WAV back.

Everything happens on your Mac. There is no account, no upload, and no network code in the app at all. The whole thing is Swift and Accelerate: BS.1770-4 loudness, 4× oversampled true peak, a multiband compressor and a lookahead limiter.

What it measures

Loudness follows ITU-R BS.1770-4: K-weighting, 400 ms blocks, a −10 LU relative gate. True peak is read from a 4× oversampled signal, so it catches the inter-sample peaks a sample meter misses. Every figure in the report is measured on the rendered audio, not predicted from the settings.

Delivery checks

Pick a delivery target and the master is checked against a published set of technical requirements. The Apple target follows the Apple Digital Masters technology brief: 24-bit, the native sample rate, at least 1 dB of headroom. It also encodes to 256 kbps AAC, decodes it back, and counts the samples that return over full scale. If the encode clips, the ceiling comes down and the level pass runs again.

There is a CLI

make cli
.build/release/ripcord-cli track.wav --intensity loud
.build/release/ripcord-cli track.wav --analyze
.build/release/ripcord-cli track.wav --delivery apple

It exits non-zero when a delivery check is not met, so a release script can gate on it.
